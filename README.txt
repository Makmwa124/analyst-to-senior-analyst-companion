From Analyst to Senior Analyst - companion files
Mathew Kariuki, 2026

templates/      Scoping brief, stakeholder map, saying-no scripts, promotion evidence log,
                1:1 agenda, 90-day plan (.docx/.xlsx and .md) and the request log workbook
data/           Paperbark Mutual practice data (CSV) and paperbark.db (SQLite)
book_code/      Every code example, chapter by chapter (.py and .sql)
scripts/make_data.py   The script that generated the practice data

Templates: make a copy and fill it in. Keep the stakeholder map private.

Code: open this folder in VS Code (File > Open Folder) and run the examples from here,
e.g. python book_code/ch04_estimates.py. Paths such as "data/requests.csv" assume this
folder is the working directory.

Install: pip install pandas numpy
Tested with Python 3.13 and pandas 3.0.

Paperbark Mutual and all people and businesses in the data are fictional; the data is simulated.
